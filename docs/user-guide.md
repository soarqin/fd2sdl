# 使用指南

无配置文件时，SDL 版沿用原版游戏节奏，并启用第 23 章罗德曼招募与 30 级经验归零修正。载入配置后，游戏按所选节奏（P）和规则（R）运行。窗口、音量、路径、键位和手柄属于宿主项（H），可以自由调整。Nuked OPL3 保留原生音色与响度。

## 游戏资源和启动模式

桌面版默认从当前工作目录读取原版文件。Windows 发布包的 `play.cmd` 以自身所在目录作为工作目录。如果当前目录没有下列游戏文件，而 `original_game/FDOTHER.DAT` 存在，程序会读取 `original_game/`。在启动设置的「路径」页可以输入或粘贴其他数据目录。

「路径」页检查以下 12 个文件是否存在且非空。各游戏入口随后读取自己需要的文件。文件名按表中大小写保存，以便在区分大小写的文件系统上读取。

| 用途 | 文件 |
|---|---|
| 动画和战斗演出 | `ANI.DAT`、`BG.DAT`、`FIGANI.DAT`、`TAI.DAT` |
| 地图、角色与图形 | `FDFIELD.DAT`、`FDICON.B24`、`FDSHAP.DAT` |
| 文本和其他资源 | `DATO.DAT`、`FDOTHER.DAT`、`FDTXT.DAT` |
| 音乐 | `FDMUS.DAT`、`SAMPLE.AD` |

运行不需要 `FD2.EXE`、`FD2.TMP` 或预置存档。程序直接读取 `FDICON.B24`，不生成供 DOS 原版使用的 TMP 缓存。

选择「启动游戏」后进入片头和标题。已有配置且关闭「每次启动时显示设置」时，无参数启动直接进入片头。`--new-game-play` 从新游戏引导开始，随后进入正式战场流程。`--field-play 0` 是独立布阵调试入口，跳过开场移动，也不进行应用层跨关交接；它的画面不是自然开场终态。调试方式见[工具速查](tools/README.md)。

## 启动设置

首次运行显示启动设置。以后可用 `--setup` 随时重开，也可在「路径」页打开「每次启动时显示设置」。调试入口默认跳过引导，在调试参数旁加 `--setup` 可进入同一个设置窗口。

- 在「路径」页点击「游戏数据目录」，或选中该行后按 Enter，即可编辑路径。按 Enter 确认后可查看资源数量和首个缺失文件。「仅保存」可保留设置。「启动游戏」检查文件、保存配置，然后进入游戏。
- 「画面」调整窗口、比例和像素滤镜。「声音」选择输出设备，用「试听」检查主音量和静音。
- 「键盘」和「手柄」按游戏中的虚拟键列出绑定。选中一行，再按物理键、手柄按钮或拨动左摇杆即可录入。修饰组合在本页选择，Delete 清除当前行的自定义绑定。每页可单独恢复默认映射。
- 「节奏与规则」里的「逐字速度」控制剧情对话、战场提示和城镇服务提示的文字显示。「动画速度 (%)」控制角色行走、回合切换动画、游标回到角色位置和战斗演出。
- 「升级属性成长」默认使用「原版随机」。上下限不同时，原版从下限到上限减 1 之间抽取。选择「最大成长+1」「最大成长」或「最小成长」即启用升级成长补丁，分别取成长表上限、原版能抽到的最大值和下限。上下限相等时，三档均取该固定值。
- 「第 23 章罗德曼加入」默认选「蜜蒂不加入则罗德曼加入」。「必定加入」允许蜜蒂与罗德曼同时在队。两种方式均要求在第 15 回合前获胜。
- 「修正 30 级经验归零」默认开启，将升级时清零剩余经验的等级从 30 改为 40。
- 「AI 攻击高防御目标」默认关闭。开启后，AI 也会给高防御目标普通攻击优先级。
- 「休息不回血」默认关闭。开启后，玩家和 AI 的单人战场休息跳过回血。回合切换时的整组恢复沿用原有规则。
- 系统首选语言为简体中文时，启动设置默认显示简体中文。其他语言默认显示繁体中文。按 F2 或点击右上角按钮可在当前窗口切换。
- 「恢复默认」修改窗口中的值。「仅保存」写入后退出。「退出」放弃本次修改。键盘用 Tab 切换页面栏、设置行和底部按钮，方向键选择或调整，Enter 确认，PgUp／PgDn 翻页。鼠标可点击并滚动。手柄用十字键选择，A 确认，B 返回，LB／RB 翻页，X 切换区域。
- 编辑路径时可直接输入 UTF-8 文本或用 Ctrl+V 粘贴，Enter 接受，Esc 取消。手柄也可用方向键选择字符，A 输入，X 删除，Y 接受。路径中超出内嵌字库的字符显示为问号，保存时保留原文字。

## 配置文件

程序依次使用以下来源。显式指定的文件即使尚未创建，也会成为本次的保存目标。

1. `--config <路径>`，或用 `--no-config` 禁用配置读写。
2. 环境变量 `FD2SDL_CONFIG`，值为 `none` 时禁用配置。
3. 当前工作目录中已有的 `fd2sdl.cfg`。
4. SDL 用户首选项目录 `SDL_GetPrefPath("fd2sdl", "fd2sdl")` 下的 `fd2sdl.cfg`。首次运行默认保存在这里。

例如，`fd2sdl --setup --config ./fd2sdl.cfg` 会创建或编辑便携配置。`fd2sdl --no-config` 用默认设置直接运行。`--no-config --setup` 可以查看引导窗口，启动时使用默认值。`FD2SDL_SAVE_PATH` 始终优先于 `[paths] save_path`。相对路径从程序的工作目录解析。

文件采用 UTF-8。`#` 开头的行是注释，分组和键名忽略大小写。数值超出范围时取最近的边界，无效值回退该项默认值。写回保留未知项和注释，通过同目录的临时文件替换目标。损坏且无法读取的配置使用默认值，原文件保留。使用独立的游戏数据目录时，配置和存档请放在该目录以外。

| 分组 | 项 | 默认值及可选值 |
|---|---|---|
| `paths` | `game_dir`、`save_path` | 当前工作目录、`FD2.SAV`。原有的 `original_game/` 布局仍可使用 |
| `launcher` | `show_on_start` | `off`。`on` 表示每次正常启动显示引导 |
| `video` | `window_scale`、`aspect_4_3` | `3`（1–8）、`off`／`on`。默认窗口 960×600，开启校正后每倍为 320×240 |
| `video` | `fullscreen`、`scale_mode` | `off`／`desktop`。缩放默认 `integer`，另可选 `letterbox`（等比留边）或 `stretch`（拉伸） |
| `video` | `filter`、`renderer` | `nearest`／`linear`。渲染驱动留空时由 SDL 选择 |
| `audio` | `volume`、`mute`、`device` | `100`（0–100）、`off`／`on`、空。设备名不可用时回退系统默认设备。音量和静音作用于最终播放输出 |
| `input` | `gamepad_deadzone` | `50`（0–99，百分比） |
| `rules` | `level_up_growth` | 默认 `random`（原版随机）。`max`、`max_minus_one`、`min` 分别对应「最大成长+1」「最大成长」「最小成长」。设置作用于新游戏和读档后的后续升级 |
| `rules` | `rodman_recruitment` | 默认 `without_mitty`（蜜蒂不加入则罗德曼加入），可选 `always`（必定加入） |
| `rules` | `fix_level_30_experience`、`ai_attack_high_defense`、`disable_rest_healing` | 可选 `off`／`on`，默认值依次为 `on`、`off`、`off` |
| `pacing` | `key_repeat_delay_ms`、`key_repeat_rate_ms` | `500`（1–5000 ms）、`33`（1–1000 ms） |
| `pacing` | `text_speed` | 默认 `normal`，可选 `fast`／`instant` |
| `pacing` | `animation_speed` | 默认 `100`（25–400，百分比） |
| `pacing` | `new_game_battle_effect`、`new_game_info_board` | `full`／`short`、默认 `on`。只设置新游戏的初值，读档恢复存档里的选项 |

上表中 `pacing` 属于 P 级，`rules` 属于 R 级，其余属于 H 级。等待时长会影响头像眨眼消耗的共享随机数。节奏或规则取非默认值时，启动设置页首和游戏窗口标题显示「自定义节奏与规则」。规则项作用于新游戏及读档后的后续事件和战斗。

## 按键

| 操作 | 按键 |
|---|---|
| 移动光标／选择菜单项 | 方向键、数字小键盘 8／2／4／6 |
| 确认 | Enter、Space、数字小键盘 0／Enter |
| 取消或返回 | Esc、Delete、数字小键盘小数点 |
| 单位详情 | F2／Home；有法术时按任意普通键翻到法术页，再按一次关闭 |
| 全场地图 | F1／Page Up；任意普通键关闭，焦点不变 |
| 退出程序 | 关闭窗口 |

在玩家阶段的空格上确认可打开系统菜单。用 END 结束回合。次级菜单默认选中战况总览，Save 需向左选择；确认框默认 YES，左选 YES、右选 NO，Esc 取消。March 会向当前焦点批量行军并推进整轮。FULL／SHORT 和信息板设置随存档保存和恢复。

### 自定义键位和手柄

以下示例把 J 和空格作为 Enter，K 作为 Esc，L 作为 Shift+F1。等号左侧是游戏收到的虚拟键，右侧是物理键列表。未列入绑定的物理键保留原行为，包含数字小键盘。Shift、Ctrl、Alt 等修饰键保留物理状态。一个物理源只对应一个虚拟键，多个物理源可共享同一个虚拟键，最后一个松开后停止长按。

```ini
[keyboard]
Enter = Return, Space, J
Esc = Escape, K
Shift+F1 = L

[gamepad]
south = Enter
east = Esc
stick_up = Up
```

手柄配置从物理位置映射到虚拟键，`none` 可清除该源。游戏使用首个可用的 SDL 手柄。拔出后释放它按住的键，再接入下一只可用手柄。左摇杆有死区和回差，斜推只取主轴方向。键盘和手柄共用游戏的长按重复。

| 手柄默认位置 | 对应按键 | 用途 |
|---|---|---|
| 十字键、左摇杆 | 方向键 | 移动、选择 |
| 南／东（A／B） | Enter／Esc | 确认、取消 |
| 西／北（X／Y） | F2／F1 | 单位详情、全场地图 |
| LB／RB | Z | 轮换焦点 |
| Back／Start | G／Space | 原版 G 键、空格确认 |

## 战场操作

- 移动确认后，上／左／右／下对应攻击／法术／物品／待机。未提交动作时，取消外层指令菜单会恢复移动前状态。
- 法术列表显示角色实际拥有的技能。普通施法者移动后不能施法；MP 不足时确认仍留在列表。目标选择取消后返回列表首项，攻击目标取消直接回指令菜单。传送另需选目的格。
- 物品菜单包含 Use、Give、Equip、Drop。Use 的目标取消回列表，列表取消回物品菜单。装备或丢弃不会结束行动，稍后取消移动也不会撤销装备或丢弃。Give 向相邻友军交接，满包时交换；成功后取消外层指令会保留位置和库存并结束行动。
- 准备阶段的商店支持原货单上的购买、出售、装备和转交；转交不进行战场的满包交换。教会按原条件提供复活和转职。确认的业务结果不会因为随后返回菜单而撤销。

## 存档和支持范围

默认存档为工作目录的 `FD2.SAV`。要验证旧档，请复制到 `original_game/` 之外，并将 `FD2SDL_SAVE_PATH` 指向副本。不要将证据目录用作可写存档路径。

- 正式应用流程按已确认的绑定支持 stage 0–29 的对应战斗、回合、事件、准备交接和活动恢复。26 坏结局与 29 终章保持原出口；resource 30 仅供内部尾声使用。
- 标题 CONTINUE 按关卡和资源检查恢复活动快照。标题 LOAD 可读取有效准备存档，酒店 Load 不接收 NoTown 目标。准备页保留最多 32 人的持久队伍；出阵按原条件选择 16 或 20 人，未出阵者保留。
- 未解码的事件、未知资源和越界状态不会用近似结果替代。默认拒绝第 255 回合或外来的 32 人结局名单，不保证任意外来存档可恢复。保留 Nuked OPL3 的音色与响度，不承诺逐像素、逐采样或 DOS 硬件等价。

核实过的原版范围及例外见[历史证据索引](history.md)。
